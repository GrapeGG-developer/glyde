# Changelog

## 2.0.0

Большое обновление: GT Unblock теперь самостоятельное приложение, аналог ByeByeDPI.

- Более 40 сервисов вместо 12: WhatsApp, Signal, Viber, Threads, Snapchat, TikTok, Twitch, Reddit, Roblox, GitHub, Google Meet, Patreon, Medium, новости, торрент-трекеры и другие
- Экран «Сервисы»: категории, поиск, выбор нужных, подбор только для выбранных
- Свои сайты: добавление доменов, вставка списка и импорт хостлиста из файла
- Подбор для одного сервиса долгим нажатием, быстрый подбор стал быстрее
- «Проверка сети»: подмена DNS, блокировка по IP или DPI для каждого сервиса и работа обхода, отчёт можно отправить
- Тест скорости: загрузка, пинг и джиттер
- Обмен настройкой через код и QR-код
- Новый дизайн Aqua Aero 3D: живая стеклянная сфера с жидкостью, подводный фон на GPU, параллакс от наклона телефона, глянцевые Aqua-кнопки, новые иконки
- Собственный шрифт Glasswave с кириллицей
- Новые звуки подключения, отключения, окончания подбора и ошибки

## 1.0.0

Первый выпуск GT Unblock.

- Обход блокировок DPI без root через локальный VPN, без сервера
- Автоматический подбор стратегии для каждого сервиса: быстрый (около 30 секунд) и полный
- Определение оператора и облачная база стратегий
- Выбор приложений, режим «только прокси» (SOCKS5), DNS через HTTPS, блокировка QUIC
- Плитка в шторке, виджет, автозапуск, постоянный VPN
- Экспертный режим: ручной выбор стратегий, свои параметры, импорт и экспорт, журнал
- Автообновления и бета-канал
- Оформление в стиле Windows 7 Aero, светлая тема и Aero Dark, выбор цвета стекла
- Русский и английский языки
