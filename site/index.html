Одна кнопка — и YouTube, Telegram, Discord снова работают

Glyde 26.11 Andromeda
Скачать для Android Исходный код

Не VPN

Серверов нет. Трафик идёт напрямую к сайтам, Glyde меняет только форму пакетов прямо на телефоне.

Ноль настроек

Glyde сам подбирает рабочую стратегию под вашего провайдера и чинит её, если что-то поменялось.

Быстрый Telegram

Встроенный прокси через WebSocket: картинки и видео грузятся без вечного «Соединение…».

Звонки и игры

Обход для UDP и QUIC: голосовые каналы Discord и звонки работают лучше.

Для экспертов

Все параметры движка, конструктор команды, свои стратегии, журнал движка.

Открытый код

GPL-3.0, сборки в GitHub Actions и проверка подлинности APK прямо в приложении.

Как это работает

Ваш телефон→Glyde меняет форму пакетов→Фильтр не узнаёт→Сайт открывается
